# Movie Collection by Timedoor

## How to install:
- Open terminal inside VS Code
- Run this code: npm install --legacy-peer-deps

## How to run:
- Open terminal inside VS Code
- Make sure the devices is connected to the laptop/computer USB
- To check, open the terminal and run this code: adb devices.
- Run this code: npx react-native run-android

Notes:

- Make sure the devices USB Debugging dan verify apps over USB is on. (on developer options)
- Node.js version should be 18 (download: https://nodejs.org/dist/v18.20.8/node-v18.20.8-x64.msi).
- If adb devices showing unauthorized, turn off and on the USB debugging and verify apps over USB again.
